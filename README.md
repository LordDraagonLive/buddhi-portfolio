# Buddhi Adhikari Portfolio

Static portfolio site for Buddhi Adhikari, built with HTML, CSS, and JavaScript for GitHub Pages.

## Files

- `index.html` - portfolio structure and content
- `styles.css` - responsive visual design
- `script.js` - project filtering and footer year
- `.nojekyll` - keeps GitHub Pages from running Jekyll
- `.github/workflows/pages.yml` - GitHub Actions deployment workflow

## Source Material

Content was compiled from the CV PDF, LinkedIn profile PDF, GitHub public repository metadata for `LordDraagonLive`, and the live HelaGen website.
